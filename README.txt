STYLEAURA SHOPPING WEBSITE
========================

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the extracted StyleAura_Shopping_Website folder.
3. Double-click index.html.
4. The website opens in your browser. No PowerShell, server, or installation required.

FILES
- index.html       Main website page
- css/style.css    All website styling and responsive layout
- js/products.js   Product catalogue data
- js/app.js        Search, filters, wishlist, cart, newsletter interactions
- assets/images/   Local fashion images used by the website

FEATURES
- Responsive fashion storefront
- Product catalogue, category filters and search
- Wishlist and shopping cart saved in browser local storage
- Quantity controls and subtotal
- Newsletter demo interaction

NOTE
This is a front-end demo. Checkout does not take real payments or create real orders.
The website uses local image files and works offline after extraction. Google Fonts may
fall back to system fonts when offline.
